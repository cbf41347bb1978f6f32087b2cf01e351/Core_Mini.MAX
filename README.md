# Core_Mini.MAX & Core_mini.MAX__PCD

Arduino mega2560で制作した自作コンピューター関連プロジェクトです。
Arduino mega2560とCore_Mini.MAXnに合わせた独自基板です。

## 概要

Core_Mini.MAXは、Arduino mega2560を使用して制作しています。
Core_Mini.MAX__PCDは、EasyEDAを使用して制作しています。

## 使用環境

- Arduino mega2560
- C++
- Arduino IDE
- EasyEDA

## ファイル

`Core_Mini.MAX.ino`
メインプログラム
`Core_Mini.MAX__PCD`
メイン基板
